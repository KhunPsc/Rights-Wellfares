# ภาพรวมสวัสดิการ การไฟฟ้าส่วนภูมิภาค (กฟภ.)

ฐานความรู้นี้ครอบคลุมสวัสดิการของ **พนักงาน** (ผู้ปฏิบัติงาน — บรรจุประจำ รับค่าจ้างรายเดือน) และ **ลูกจ้าง** กฟภ. ซึ่งใช้กฎคนละชุด:
- พนักงาน: ระเบียบกองทุนสงเคราะห์ (รักษาพยาบาล [[ระเบียบกองทุน รักษาพยาบาล 2559|2559]] + ฉ.2 2564 + ฉ.3 2565, ค่าเล่าเรียน 2560 + ฉ.2 2563) และระเบียบ กฟภ. (เงินช่วยเหลือบุตร 2561, คลอดบุตร 2561)
- ลูกจ้าง: [[คำสั่ง พ.(ท) 1-2565 สวัสดิการลูกจ้าง]] ฉบับเดียว
- แนวปฏิบัติการตรวจจ่าย: [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] (44 ข้อ)

## เปรียบเทียบพนักงาน / ลูกจ้าง
| เรื่อง | พนักงาน | ลูกจ้าง |
|---|---|---|
| ครอบครัว | คู่สมรส บุตร (ไม่จำกัด) บิดามารดา | คู่สมรส บุตรคนที่ 1–3 |
| รพ.ราชการ | 100% IPD+OPD | 100% IPD+OPD |
| รพ.เอกชน IPD | 50% | 50% ≤ 8,000 บาท/30 วัน |
| รพ.เอกชน OPD + คลินิก | ≤ 3,600 บาท/ปี | เบิกไม่ได้ |
| ค่าห้อง+อาหาร/วัน | 1,500 (ครอบครัว 1,100) | 1,000 |
| เงินช่วยเหลือบุตร | 500 บาท/เดือน อายุ ≤ 20 | 200 บาท/เดือน อายุ ≤ 18 คนที่ 1–3 |
| คลอดบุตร | 1,200 บาท/ครั้ง | — (ไม่มีในคำสั่ง) |
| ค่าเล่าเรียน | ถึงปริญญาตรี อายุ 3–25 | ถึงปริญญาตรี อายุ 3–25 คนที่ 1–3 |
| ค่าทำศพ / ทุพพลภาพ | — (ไม่อยู่ในชุดเอกสาร) | 3 เท่าค่าจ้าง ≥ 40,000 / 33.33% 15 ปี |

รายละเอียดแต่ละเรื่อง: [[index]]

## หลักที่ใช้ซ้ำทุกเรื่อง
- **มีสิทธิที่อื่นต้องใช้ที่อื่นก่อน** แล้วเบิก กฟภ. เฉพาะส่วนที่ขาด (ยกเว้นประกันสุขภาพส่วนตัว) — [[การใช้สิทธิซ้ำซ้อนกับหน่วยงานอื่น]]
- **ยื่นเบิกภายใน 90 วัน** เป็นส่วนใหญ่ — [[กำหนดเวลายื่นเบิก]]
- **คู่สมรสทำงานทั้งคู่**: ส่วนใหญ่ให้ฝ่ายสามีใช้สิทธิ (ยกเว้นคลอดบุตรให้ภรรยา)
- **เบิกเกินสิทธิต้องคืนใน 30 วัน** ทุจริตหมดสิทธิ

## ช่องว่างของฐานความรู้

ไม่ทำตามที่ผู้ดูแลตัดสินใจ (30 ต.ค. 2569): ภาคผนวกของคู่มือ กฟน.1, ตารางอำนาจอนุมัติการเดินทาง (บัญชี 1), ระเบียบต้นฉบับของเรื่องที่มีแค่สรุปในคู่มือ กฟน.1
