# ค่ารักษาพยาบาล พนักงาน (ผู้ปฏิบัติงาน)

ตาม [[ระเบียบกองทุน รักษาพยาบาล 2559]] และที่แก้ไขเพิ่มเติม ([[ระเบียบกองทุน รักษาพยาบาล ฉ.2 2564]], [[ระเบียบกองทุน รักษาพยาบาล ฉ.3 2565]])

## สรุปสั้น
| สถานพยาบาล | คนไข้ใน (IPD) | คนไข้นอก (OPD) |
|---|---|---|
| รพ.ราชการ | เท่าที่จ่ายจริง | เท่าที่จ่ายจริง |
| รพ.เอกชน | **50%** ของที่จ่ายจริง (รายการที่ระเบียบให้เบิก) | เท่าที่จ่ายจริง รวมกับคลินิก **≤ 3,600 บาท/ปี** |
| คลินิกเอกชน | — | เท่าที่จ่ายจริง รวมกับ OPD รพ.เอกชน **≤ 3,600 บาท/ปี** |
| ค่าห้อง+อาหาร (IPD ทุกที่) | พนักงาน ≤ 1,500 / ครอบครัว ≤ 1,100 บาท/วัน | — |
| เจ็บป่วยจากการปฏิบัติหน้าที่ | 100% ทุกที่ | 100% ทุกที่ |
| ประจำและรักษาใน**พื้นที่พิเศษ** | + อีก 25% ของใบเสร็จ | + อีก 25% ของใบเสร็จ |

แหล่ง: [[ระเบียบกองทุน รักษาพยาบาล 2559]] ข้อ 18, 21, 22 · [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 7, 35 · ค่าห้อง: [[ค่าห้องและค่าอาหาร]]

## ใครมีสิทธิ
ดู [[ผู้มีสิทธิและบุคคลในครอบครัว]] — ครอบครัวต้องรอพนักงานบรรจุครบ 6 เดือน

## รพ.ราชการ
เบิกได้ทั้ง IPD และ OPD เท่าที่จ่ายจริง ตามระเบียบและบันทึกเวียนที่ให้เบิกได้ ([[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 7.4)
- สสจ., สสอ., สถานีอนามัย, รพ.ฟื้นฟูสมรรถภาพทางการแพทย์ลำปาง = สถานพยาบาลของราชการ — ดู [[สถานพยาบาลที่มีหลักเกณฑ์เฉพาะ]]
- ใช้หนังสือรับรองสิทธิให้ รพ. เรียกเก็บจาก กฟภ. ได้ — ดู [[หนังสือรับรองสิทธิและการอนุมัติจ่าย]]

## รพ.เอกชน และคลินิก
- **IPD**: 50% ของที่จ่ายจริง ตามรายการที่ระเบียบให้เบิก
- **OPD รพ.เอกชน + คลินิกเอกชน**: เท่าที่จ่ายจริง รวมกันไม่เกิน **3,600 บาท/ปี** (คลินิก: กสก.(สก.)2568/2564 ลว. 9 ธ.ค. 2564)
  - แนบใบรับรองแพทย์ (คลินิก: เมื่อใบเสร็จไม่บอกว่ารักษาโรคอะไร), รายละเอียดเวชภัณฑ์/ค่าบริการเหมาจ่าย (ถ้ามี) — คลินิกที่ไม่มีใบรายละเอียด ให้แพทย์หรือเจ้าหน้าที่เขียนรายการลงในใบเสร็จหรือใบรับรองแพทย์ได้
  - โรคผิวหนัง: แนบใบรายการยา และต้องไม่เกี่ยวกับความงามหรือลดความอ้วน
- **ใช้วงเงิน 3,600 ของอีกคนได้**:
  - สามีภรรยาเป็นพนักงานทั้งคู่ ฝ่ายหนึ่งใช้หมดแล้ว ใช้วงเงินที่เหลือของอีกฝ่ายได้ แนบรายงาน T-code ZBNR016 ของฝ่ายแรก
  - มารดาป่วย มีบุตรเป็นพนักงาน 2 คน เบิกกับคนใดก็ได้ ส่วนที่เกินคนแรกนำไปเบิกกับคนที่สอง แนบ ZBNR016 ของคนแรก
- **เบิกผิดประเภทข้ามปีงบประมาณ** (เช่น นำ OPD เอกชนไปรวม IPD): เบิกใหม่ตามสิทธิคงเหลือของปีก่อนได้ โดยตั้งหนี้เป็นค่าใช้จ่ายทั่วไป (T-code F-43) — กฟฟ. ต้องคุมไม่ให้เกินสิทธิคงเหลือเอง เพราะระบบไม่คุมให้

แหล่ง: [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 7.5

## ป่วยหนักกะทันหัน / ฉุกเฉิน
ดู [[ค่ารักษาพยาบาลกรณีฉุกเฉิน]]

## แพทย์สั่งให้ไปทำ/ซื้อข้างนอก
แล็บ 50%, เอกซเรย์ 100%, ล้างไต ≤ 2,000 บาท/ครั้ง, ยา 100%, อวัยวะเทียมตามอัตรากระทรวงการคลัง — ดู [[รายการค่ารักษาที่เบิกได้และเบิกไม่ได้]]

## หลักฐานกรณีคนไข้ใน
แนบหนังสือรับรองการเจ็บป่วยหรือใบรับรองแพทย์ — ยกเว้นกรณีออกหนังสือรับรองสิทธิให้ รพ.ราชการ ([[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 18)

## ค่าพยาบาลพิเศษ
อาการขั้นอันตรายร้ายแรง แพทย์รับรองว่าต้องมีพยาบาลพิเศษ: ≤ **200 บาท/วัน** ไม่เกิน 3 วันต่อการเจ็บป่วยครั้งหนึ่ง จ้างได้ครั้งละ 1 คน จำเป็นต่อจ้างได้อีก ≤ 3 วัน (แพทย์ชี้แจงความจำเป็นเป็นราย ๆ) ([[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 17)

## รักษานานผิดปกติ (เกิน 3 เดือน)
- โรคเรื้อรัง (หัวใจ เบาหวาน อัมพาต ไตวาย ปอด ฯลฯ) ไม่มีโรคแทรกซ้อนอันตราย สภาพเป็นการฟื้นฟูดูแล → **ไม่ถือเป็นค่ารักษาที่เบิกได้**
- IPD เกิน 3 เดือนและเบิกต่อเนื่อง → ต้นสังกัดส่งประวัติให้ กสก. ทุกเดือน เพื่อเสนอคณะทำงานและคณะกรรมการกองทุน
- เบิกได้เมื่อมีโรคแทรกซ้อนที่อาจอันตรายถึงชีวิต และแพทย์เห็นว่าต้องรักษาแบบผู้ป่วยในเป็นครั้งคราว

แหล่ง: [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 31

## รพ. มีส่วนลด
- ส่วนลดรวม (เช่น 10%) ไม่ระบุรายการ → หักออกจากทุกรายการก่อน แล้วคำนวณสิทธิ (ค่าห้องตามเพดาน ค่ารักษา 50%)
- ส่วนลดระบุรายการ → หักเฉพาะรายการนั้น รายการอื่นคิดจากยอดเต็ม
- รพ.เอกชนมีข้อตกลงส่วนลดกับ กฟภ. แต่ลดไม่ครบหรือไม่ลด → เจ้าหน้าที่ต้องหักให้ครบตามข้อตกลงก่อนคำนวณสิทธิ

แหล่ง: [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 33–34

## เจ็บป่วยเนื่องจากการปฏิบัติหน้าที่
- ผู้มีสิทธิ: ผู้ปฏิบัติงาน หรือผู้ทดลองปฏิบัติงาน ที่ประสบอันตรายจากการทำงานให้ กฟภ. หรือป่วยด้วยโรคจากลักษณะ/สภาพงาน
- รพ.ราชการและเอกชน ทั้ง IPD/OPD: ค่ารักษา ค่าห้อง ค่าอาหาร อวัยวะเทียม และพยาบาลพิเศษ (ถ้าแพทย์เห็นว่าจำเป็นอย่างยิ่ง) **เบิกเต็มจำนวน**
- ขั้นตอน:
  - จ่ายเงินไปแล้ว → ยื่นคำร้องพร้อมผลคณะกรรมการสอบข้อเท็จจริงที่ ชผก. แต่งตั้ง และคำวินิจฉัย ชผก. หรือมติ กรส. ผ่านผู้บังคับบัญชา
  - ให้ กฟภ. ออกหนังสือรับรองให้ รพ.เอกชน → ผู้บังคับบัญชารายงานและขออนุมัติ รผก.(ท) ให้ ชผก. ออกหนังสือรับรอง เมื่อได้ใบแจ้งหนี้ ส่งหลักฐาน (อนุมัติ รผก.(ท), สก.2-ป.59, สำเนาหนังสือรับรอง, ใบแจ้งหนี้) ให้ กสก.

แหล่ง: [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 35, 40.6

## พื้นที่พิเศษ
พนักงานที่ (1) ปฏิบัติงานประจำในพื้นที่พิเศษ (2) มีสิทธิตามระเบียบอยู่แล้ว และ (3) รักษาพยาบาลในพื้นที่พิเศษ ได้รับเงินช่วยเหลือ**เพิ่มอีก 25% ของค่ารักษาตามใบเสร็จ** ทั้งตนเองและครอบครัว — ครอบครัวต้องอยู่ร่วมกับพนักงาน · พื้นที่พิเศษ = ตามระเบียบการจ่ายเงินสวัสดิการสำหรับการปฏิบัติงานในพื้นที่พิเศษของ กฟภ. (ยังไม่อยู่ในชุดเอกสาร) ([[ระเบียบกองทุน รักษาพยาบาล 2559]] ข้อ 4.13, 22)

## ไปรักษาต่างท้องที่
- แพทย์ รพ.ราชการแนะนำ และผู้บังคับบัญชาเห็นชอบ → **เฉพาะพนักงาน**เบิกค่าพาหนะและค่าเช่าที่พักก่อนเข้ารักษาได้ ตามระเบียบค่าใช้จ่ายในการเดินทางไปปฏิบัติงาน แต่**ไม่ได้เบี้ยเลี้ยง**
- ไปเองตามความประสงค์ → รักษาที่ รพ.ราชการในท้องที่อื่นได้ แต่ไม่ได้ค่าพาหนะ ที่พัก หรือเบี้ยเลี้ยง

([[ระเบียบกองทุน รักษาพยาบาล 2559]] ข้อ 8)

## อื่น ๆ จากระเบียบ
- สถานพยาบาลไม่มียา เลือด น้ำยา/อาหารทางเส้นเลือด ออกซิเจน หรืออวัยวะเทียม → ซื้อจากร้านเอกชนได้เมื่อแพทย์หรือหัวหน้าสถานพยาบาลลงชื่อรับรอง (ข้อ 10)
- ต้อกระจกผ่าตัดเอาแก้วตาออก → แว่นตา **หรือ** คอนแทคเลนส์อย่างใดอย่างหนึ่ง ครั้งเดียว ไม่เกินอัตรากระทรวงการคลัง (ข้อ 18)
- ได้ค่าสินไหมทดแทนค่ารักษาจากบุคคลอื่น → เบิกได้เฉพาะส่วนที่ขาด ถ้าเบิกไปก่อนแล้วต้องคืน (ข้อ 13) — ดู [[การใช้สิทธิซ้ำซ้อนกับหน่วยงานอื่น]]
- ทุจริตหรือกรอกเท็จ → โทษทางวินัย และหมดสิทธิตามระเบียบนี้ตลอดไป (ข้อ 17)
