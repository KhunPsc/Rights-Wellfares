# เงินสวัสดิการพื้นที่พิเศษ ค่าขนย้าย และค่าใช้จ่ายฝึกอบรม

สรุปจาก [[คู่มือตรวจสอบใบสำคัญจ่ายเงิน กฟน.1 (26 ม.ค.65)]] หน้า 106–111

## เงินสวัสดิการปฏิบัติงานในพื้นที่พิเศษ
ระเบียบ กฟภ. ว่าด้วยการจ่ายเงินสวัสดิการสำหรับการปฏิบัติงานประจำสำนักงานในพื้นที่พิเศษ พ.ศ. 2563
- พนักงานประจำ (รวมทดลองงาน) ที่ทำงานประจำสำนักงานในพื้นที่พิเศษ ตามบัญชีรายชื่อการไฟฟ้าท้ายระเบียบ (ภาคผนวก 8 ของคู่มือ — เป็นภาพ ยังไม่ได้ถอด)
- **2,000 บาท/คน/เดือน** จ่ายพร้อมเงินเดือน · ผชก. สั่งจ่าย
- ไปช่วยงาน/รักษาการแทน/ศึกษา/อบรม/ดูงานนอกพื้นที่**เกิน 15 วัน** ไม่ได้สำหรับส่วนที่เกิน 15 วัน
- เริ่มงานครั้งแรก หรือหยุดงานไม่ได้เงินเดือน ในเดือนนั้น ทำงาน**น้อยกว่า 15 วัน** ไม่ได้เดือนนั้น
- สำนักงานถูกถอดจากบัญชี หมดสิทธิตั้งแต่เดือนที่ถูกถอด

พนักงานพื้นที่พิเศษยังได้ค่ารักษาพยาบาลเพิ่มอีก 25% ของใบเสร็จ — ดู [[ค่ารักษาพยาบาล พนักงาน]] ([[ระเบียบกองทุน รักษาพยาบาล 2559]] ข้อ 22)

## ค่าขนย้ายสิ่งของส่วนตัว (ย้ายที่ทำงาน)
กรบ.(พท)834/2559
- ใช้ระยะทางเป็นเกณฑ์ เทียบระเบียบกระทรวงการคลังว่าด้วยค่าใช้จ่ายเดินทางไปราชการ พ.ศ. 2550 — ตามจริงไม่เกินอัตรากระทรวงการคลัง (อัตราไม่อยู่ในคู่มือ)
- แบบ **รบ.18-ร.59** · หัวหน้าหน่วยงาน (ผจก.กฟส. ขึ้นไป) ทั้งต้นสังกัดเดิมและใหม่รับรองว่าขนย้ายจริง · **รองผู้ว่าการบริหารทรัพยากรมนุษย์**อนุมัติ
- หลักฐาน: รายการสิ่งของ, **ภาพถ่ายการขนย้ายต้นทางและปลายทางเห็นรถ**, สำเนาบิล/ใบเสร็จจากผู้รับจ้าง, สำเนาใบขับขี่และทะเบียนรถผู้รับจ้าง

## ค่าใช้จ่ายฝึกอบรมและสัมมนา
ระเบียบ กฟภ. ว่าด้วยการฝึกอบรมและสัมมนา พ.ศ. 2560
- ค่าสถานที่ พิธีเปิด-ปิด เครื่องเขียน ประกาศนียบัตร เอกสาร หนังสือ สื่อสาร เช่าอุปกรณ์ กระเป๋า และอื่นที่จำเป็น: ตามจริงอย่างประหยัด · ของที่ระลึก: ไม่เกินที่ ป.ป.ช. กำหนด
- ผชก. อนุมัติ: ใช้งบอบรมนอกแผนจัดเอง · ส่งพนักงานไปอบรมภายนอก (นอกบัญชีภาคผนวก 7) ค่าลงทะเบียน ≤ **30,000** บาท

**ค่าสมนาคุณวิทยากร (บาท)**
| ประเภท | ผู้เข้าอบรมต่ำกว่า อฝ. | ผู้เข้าอบรม อฝ. ขึ้นไป |
|---|---|---|
| วิทยากรภายนอก | ≤ 1,600/ชม. | ≤ 2,500/ชม. |
| วิทยากรภายนอกพิเศษ | ≤ 2,500/ชม. | ≤ 10,000/ชม. |
| ผู้ช่วยวิทยากรภายนอก / พิเศษ | ≤ 1,200 / ≤ 3,600 ต่อวัน | |
(ผู้เข้าอบรมผสม ใช้กลุ่มที่มากกว่าเป็นเกณฑ์)

| วิทยากรภายใน | อัตรา |
|---|---|
| บรรยายภาษาไทย ภาคทฤษฎี / ภาคปฏิบัติ | 500 / 150 ต่อชั่วโมง |
| บรรยายภาษาต่างประเทศ | 1,000/ชม. |
| ฝึกภาคสนามฮอทไลน์/เชื่อมสายแรงสูง | 150/วัน |
| ผู้ช่วยวิทยากรภายใน / พิเศษ (Workshop) | 100 / 300 ต่อชั่วโมง |
- ผู้ช่วยวิทยากรมีได้ไม่เกิน 3 คนต่อหลักสูตร เฉพาะหลักสูตรที่แบ่งกลุ่ม · อภิปรายเป็นคณะจ่ายตามเวลาตลอดช่วง

**อาหารว่าง** (ภาคอบรมต้อง ≥ 2.30 ชม.): สำนักงาน กฟภ. ≤ 25 · สถานที่ราชการ ≤ 35 · เอกชน ≤ 80 บาท/คน/มื้อ

**ค่าพาหนะ**: ผู้เข้าอบรมเบิกตามระเบียบเดินทาง (ผู้จัดจัดรถให้แต่ไม่ไป ต้องแจ้งเป็นหนังสือและขอความเห็นชอบต้นสังกัด) · วิทยากรภายนอกรถส่วนตัว ไป-กลับ ≤ 100 กม. เหมา **500** บาท/ครั้ง เกิน 100 กม. ≤ **1,500** บาท · รถสาธารณะตามจริง · วิทยากรภายในตามระเบียบเดินทาง

เบี้ยเลี้ยงเมื่อหน่วยงานจัดอาหารให้: ดู [[ค่าใช้จ่ายเดินทางไปปฏิบัติงาน]] (3 มื้อ = 1 วัน)

## ประชุมชี้แจง
หลักเกณฑ์การประชุมชี้แจง พ.ศ. 2560 — ค่าสถานที่ พิธี เอกสาร และอื่นตามจริง · ของที่ระลึกตามเกณฑ์ ป.ป.ช. · วิทยากรภายนอกและอาหารว่างใช้อัตราระเบียบฝึกอบรม · ผู้ร่วมประชุมเบิกเดินทางตามระเบียบ · ประชุมในสำนักงาน หัวหน้าหน่วยงานผู้จัดลงนามเชิญ · นอกสำนักงาน ผชก. อนุมัติ
