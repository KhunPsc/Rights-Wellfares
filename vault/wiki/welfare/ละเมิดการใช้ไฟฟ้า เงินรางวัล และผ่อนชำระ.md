# ละเมิดการใช้ไฟฟ้า เงินรางวัล และการผ่อนชำระค่าเสียหาย

สรุปจาก [[คู่มือตรวจสอบใบสำคัญจ่ายเงิน กฟน.1 (26 ม.ค.65)]] หน้า 87–95

## เงินสินบน/รางวัล จับผู้ลักอุปกรณ์ระบบไฟฟ้า
ระเบียบ 2546 — อุปกรณ์ = เสา สายไฟ หม้อแปลง มิเตอร์ ฯลฯ ที่ติดตั้งแล้ว
- **ผู้นำจับ** (แจ้งเจ้าหน้าที่) **2,000** บาท · **ผู้จับ** (ฝ่ายปกครอง/ตำรวจ/ผู้มีอำนาจจับ) **2,000** บาท
- จ่ายเมื่อมีหลักฐานชัดว่าทำผิดจริง**และฟ้องศาลแล้ว**
- ผู้นำจับหลายคน: จ่ายคนแรก (พร้อมกันแบ่งตามส่วน) · ผู้จับหลายคน แบ่งตามส่วน
- ผชก. / ผจก.ชั้น 1–3 อนุมัติ

## เงินรางวัลผู้แจ้งและผู้ตรวจสอบการละเมิดการใช้ไฟฟ้า
ระเบียบ 2546 — ละเมิด = ทำการโดยมิชอบต่ออุปกรณ์ มิเตอร์ ตรา กฟภ. หรือต่อไฟตรงไม่ผ่านมิเตอร์
| ขนาดมิเตอร์ | ผู้แจ้ง | ผู้ตรวจสอบ (พนักงาน) |
|---|---|---|
| ≤ 30A 1 เฟส | 500 | 100 |
| > 30A 1 เฟส | 1,000 | 200 |
| 3 เฟส | 1,000 | 200 |
| มีค่าความต้องการพลังไฟฟ้า (Demand) | 2,000 | 400 |
- ต่อไฟตรง: ใช้ขนาดมิเตอร์ที่ กฟภ. ประเมินค่าเบี้ยปรับ
- จ่ายหลัง กฟภ. **ได้รับเงินค่าเบี้ยปรับแล้ว** (ไม่ยอมจ่าย ต้องรอศาลพิพากษาถึงที่สุด)
- จับ**ผู้รับจ้าง**ทำการละเมิดได้จนศาลลงโทษ: ผู้แจ้งได้ **5,000** บาท
- แจ้งเป็นหนังสือ (ลงวันที่ ชื่อ ที่อยู่) / แจ้งด้วยตนเองที่สำนักงาน / แจ้งวาจากับผู้ว่าการ รองผู้ว่าการ ผชก. หรือ ผจก.
- หลายคน: คนแรกก่อน (พร้อมกันแบ่งตามส่วน) · ผชก. / ผจก.ชั้น 1–3 อนุมัติ

## เบี้ยเลี้ยงพิเศษเจ้าพนักงาน (ตำรวจ ทหาร ฝ่ายปกครอง)
- ร่วมตรวจระบบสาย/งดจ่ายไฟในที่ไม่ปลอดภัย หรืออำนวยการจราจรที่คับคั่งระหว่างก่อสร้าง/ซ่อม: **500 บาท/คน/วัน** ต้องร้องขอเป็นหนังสือ (พ.(ท)7/2562)
- ร่วมตรวจมิเตอร์ บรรจุหีบห่อ/เก็บหลักฐาน เป็นพยาน หรือร่วมตรวจการใช้ไฟ (พบละเมิดหรือไม่ก็ตาม): **500 บาท/คน/ครั้ง** · ค่าส่งวัตถุพยานให้สำนักงานพิสูจน์หลักฐานตำรวจตามจริง ≤ **3,000** บาท · แนบสำเนาบัตรเจ้าหน้าที่ บันทึกการตรวจ และบันทึกขออนุมัติ (ระเบียบตรวจสอบมิเตอร์ 2559)
- ผจก. อนุมัติ

## ละเมิดทรัพย์สินระบบไฟฟ้า — เรียกค่าเสียหายและผ่อนชำระ
ระเบียบ 2563
| ผู้อนุมัติ | เรียกค่าเสียหาย | ผ่อนได้ |
|---|---|---|
| ผจก.สาขา | ≤ 50,000 | ≤ 6 เดือน |
| ผจก.ชั้น 2–3, อก. ในเขต | ≤ 500,000 | ≤ 12 เดือน |
| ผจก.ชั้น 1, อฝ.บัญชีและพลังงานไฟฟ้า | ≤ 1,800,000 | ≤ 18 เดือน |
| ผชก. | > 1,800,000 | ≤ 24 เดือน |
| รองผู้ว่าการภาค 1–4 | — | > 24 เดือน หรือนอกเกณฑ์ |
- ขอผ่อนเป็นหนังสือ กำหนดระยะชัดเจน · เกิน **300,000** บาท ต้องมีหลักประกัน (ผู้ค้ำ หนังสือค้ำธนาคาร หลักทรัพย์)
- จ่ายล่วงหน้าเกินวงเงินอนุมัติ: ผู้อนุมัติหรือสำนักกฎหมายคืนส่วนเกินได้

## ปรับปรุงค่าไฟฟ้า (มิเตอร์คลาดเคลื่อน/ชำรุด)
หลักเกณฑ์ 2559
- เกิดจาก**ผู้ใช้ไฟละเมิด**หรือการกระทำของผู้ใช้ไฟ: ดอกเบี้ยผ่อน **15% ต่อปี** หนังสือรับสภาพหนี้ ศฟ.4/2559-ป.59
- สาเหตุอื่น (มิเตอร์ชำรุด ตัวคูณผิด คิดผิด): **ไม่คิดดอกเบี้ย** ศฟ.3/2559-ป.59 (เว้นแต่ผิดเงื่อนไขการผ่อน)
| ผู้อนุมัติ | วงเงิน | ผ่อนได้ |
|---|---|---|
| ผจก.สาขา | ≤ 50,000 | ≤ 12 เดือน |
| ผจก.ชั้น 2–3 | ≤ 500,000 | ≤ 18 เดือน |
| ผจก.ชั้น 1, อฝ.บัญชีและพลังงานไฟฟ้า | ≤ 3,000,000 | ≤ 24 เดือน |
| ผชก. | ≤ 5,000,000 | ≤ 36 เดือน |
| รองผู้ว่าการจำหน่ายและบริการ | นอกเหนือจากนี้ | |

## พนักงานผ่อนชำระค่าเสียหายต่อ กฟภ.
คำสั่ง พ.(ม)79/2558 — ผู้บังคับบัญชาตามสายอนุมัติแทนผู้ว่าการ
- ต้องมี**ผู้ค้ำประกัน** · ผ่อนงวดละ**ไม่น้อยกว่า 10% ของเงินเดือน** · ไม่เสร็จใน 1 ปี นำ**โบนัส 25%** มาผ่อนด้วย · ต้องชำระครบ**ก่อนพ้นสภาพพนักงาน**
- อก./ผจก. ≤ 100,000 · อฝ. ≤ 200,000 · ผชก. ≤ 500,000 · รองผู้ว่าการ ≤ 1,000,000 · ผู้ว่าการ > 1,000,000 บาท
- นอกเกณฑ์: ≤ 1 ล้าน รองผู้ว่าการตามสายอนุมัติ / เกิน 1 ล้าน ผู้ว่าการ — อนุมัติแล้วรายงานผู้ว่าการ
