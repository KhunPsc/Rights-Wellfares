# รายการค่ารักษาที่เบิกได้และเบิกไม่ได้

## นิยาม "ค่ารักษาพยาบาล" 8 หมวด
1. ค่ายา เวชภัณฑ์ อุปกรณ์การแพทย์ เลือด/สารทดแทน น้ำยาหรืออาหารทางเส้นเลือด ออกซิเจน นมผสม ค่าเลี้ยงดูทารกแรกเกิด ยาบำรุงตามคำสั่งแพทย์
2. ค่าบริการทางการแพทย์/การพยาบาล ตรวจวินิจฉัย วิเคราะห์โรค ผ่าตัด (รวมทำหมัน) ตรวจพิเศษ ทันตกรรมเฉพาะการรักษา อุดและถอนฟัน — **ไม่รวม** ค่ารักษาพยาบาลพิเศษ และค่าธรรมเนียม/ค่าบริการอื่นที่เป็นเงินตอบแทน
3. ค่าอวัยวะเทียมและอุปกรณ์บำบัดรักษาโรค (รวมค่าซ่อม) ตามอัตรากระทรวงการคลัง
4. ค่าตรวจครรภ์ ค่าคลอด การดูแลหลังคลอด
5. ค่าสร้างเสริมสุขภาพและป้องกันโรค
6. ค่าฟื้นฟูสมรรถภาพร่างกายและจิตใจ
7. ค่ารักษาผู้ป่วยฉุกเฉินวิกฤต
8. ค่าใช้จ่ายอื่นที่จำเป็นตามที่กระทรวงการคลังกำหนด

ลูกจ้างเพิ่มอีก 2 หมวด: ค่าห้องและค่าอาหาร และค่าตรวจสุขภาพประจำปี ([[คำสั่ง พ.(ท) 1-2565 สวัสดิการลูกจ้าง]] ข้อ 4.15)

แหล่ง: [[ระเบียบกองทุน รักษาพยาบาล ฉ.2 2564]] ข้อ 4.11 · [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 15

## รายละเอียดรายการ (16.1–16.15)
| รายการ | เบิกได้ | เบิกไม่ได้ / เงื่อนไข |
|---|---|---|
| ค่ายา | ยาฉีด ยาทา ยากิน วัคซีน (รวมถึงปากกาควบคุมน้ำหนักตามเกณฑ์การแพทย์) | ยาลดความอ้วน/เพื่อความสวยงาม ยาที่เป็นเครื่องสำอาง (แก้สิว แก้ฝ้า แชมพูขจัดรังแค) — *ข้อยกเว้น:* ปากกาควบคุมน้ำหนัก (Weight Loss Injection Pen) เบิกได้เฉพาะมีความจำเป็นทางการแพทย์ตาม [[กสก.(สก) 1375-2569 ปากกาควบคุมน้ำหนัก]] (BMI ≥ 30 หรือ BMI ≥ 27 ร่วมกับโรคแทรกซ้อน หรือผู้ป่วยเบาหวาน) |
| สารอาหารทางเส้นเลือด | กลูโคส น้ำเกลือ โปรตีน | |
| โลหิต | Whole blood, PRC, FFP, Platelet, Plasma รวมค่าอุปกรณ์และค่าบริการ | |
| แล็บ / รังสี / ตรวจพิเศษ | ตรวจเลือด ปัสสาวะ ชิ้นเนื้อ · X-ray CT US MRI รังสีรักษา · EKG EMG EEG Echo ฯลฯ | |
| ทันตกรรม | อุดฟัน ถอนฟัน ขูดหินปูน รักษารากฟัน (กค. ว 246/2559) | จัดฟัน เคลือบฟลูออไรด์ เคลือบร่องฟัน รากฟันเทียม ค่าวัสดุ |
| ฝังเข็ม / นวดประคบสมุนไพร | เพื่อรักษาหรือฟื้นฟูเท่านั้น เบิก กฟภ. ได้เท่าที่จ่ายจริง (รหัส 58001, 58020, 58130) | เพื่อส่งเสริมสุขภาพหรือป้องกันโรค · ต้องมีใบรับรองจากแพทย์ที่ผ่านอบรมฝังเข็ม/แพทย์แผนจีน/แพทย์แผนไทย |
| เวชภัณฑ์ที่มิใช่ยา | ต้องแนบรายละเอียดทุกครั้ง | ป้ายข้อมือ ชุดสบู่ แปรงสีฟัน ยาสีฟัน ผ้าขนหนู คนเฝ้าไข้ |
| อวัยวะเทียม/อุปกรณ์ | ตามชื่อประเภท รหัส 4 หลัก และอัตรากระทรวงการคลัง (เช่น 1001 กะโหลกเทียม 6,000 บาท — รพ. เก็บ 8,000 เบิกได้ 6,000) | ค่าซ่อมเบิกได้เมื่อแพทย์สั่งซ่อมโดยประหยัด |
| ค่าธรรมเนียมแพทย์ / นอกเวลา รพ.ราชการ | ตามจ่ายจริง เฉพาะเมื่อเกิดจากการรักษาที่เบิกได้ | จัดฟันเบิกไม่ได้ → ค่าธรรมเนียมจัดฟันก็เบิกไม่ได้ (ทำหลายอย่างพร้อมกัน ให้ รพ. แยกค่าธรรมเนียมแต่ละรายการ) |

ตัวอย่างฝังเข็ม: รหัส 58130 ราชการให้ 250 บาท รพ. เก็บ 350 → เบิก กฟภ. ได้ 350 (อัตรารหัส 5 หลักใช้อ้างชื่อรายการ ไม่จำกัดวงเงิน) ถ้าข้าราชการในครอบครัวเบิกราชการไปแล้ว 250 → เบิกส่วนที่ขาด 100 บาทจาก กฟภ. ได้

## แพทย์ กฟภ. หรือ รพ.ราชการ สั่งให้ไปทำข้างนอก
| รายการ | เบิกได้ | เงื่อนไข |
|---|---|---|
| แล็บ | **50%** ของที่จ่ายจริง | ใบเสร็จต้องไม่มีค่าแพทย์ตรวจรักษา (ถ้ามี กลายเป็น OPD เอกชนทั้งใบ) |
| เอกซเรย์ | **100%** | ไม่มีค่าแพทย์ตรวจรักษา (ค่ายาประกอบ/แพทย์ทำ/แพทย์อ่านผล ถือเป็นค่าเอกซเรย์) |
| ล้างไต ฟอกไต ฟอกเลือด (รพ.เอกชน) | เท่าที่จ่ายจริง **≤ 2,000 บาท/ครั้ง** | รพ.ราชการไม่มีเครื่องหรือไม่พอ มีคำวินิจฉัยและหนังสือรับรองของคณะกรรมการแพทย์ รพ.ราชการที่ส่งตัว (บผ.(สก.)2067/2551) |
| ยา | **100%** | ไม่มีค่าแพทย์ตรวจรักษา (ถ้ามี ไปเบิกในวงเงิน OPD 3,600) · ระบุชื่อยา จำนวน ขนาดให้ตรงใบสั่ง |
| อวัยวะเทียม/อุปกรณ์ | ตามอัตรากระทรวงการคลัง | ประเภทในใบเสร็จต้องตรงกับกระทรวงการคลัง |

ทุกรายการ:
- ทำหรือซื้อ **ในวันที่แพทย์สั่งหรือหลังจากนั้น** เท่านั้น
- ทำ/ซื้อน้อยกว่าที่สั่งได้ มากกว่าเบิกได้เท่าที่สั่ง
- แนบใบสั่งแพทย์ ใบเสร็จ และใบรับรองรายการยา/อวัยวะเทียมที่ไม่มีจำหน่ายในสถานพยาบาล (แพทย์ กฟภ. สั่ง ไม่ต้องแนบใบรับรองนี้)

ล้างไตที่เอกชน: ค่ายากระตุ้นเม็ดเลือดแดง ค่าแล็บ ค่าแพทย์ เบิกตามข้อนี้ไม่ได้ แต่ไปเบิกในวงเงิน OPD เอกชน 3,600 บาท/ปี ได้ · ค่าอุปกรณ์ตามอัตราอวัยวะเทียมเบิกไม่ได้

อุปกรณ์ที่ต้องระวัง:
- พยุงข้อศอก/ข้อเข่า **ทำจากผ้ายืด เบิกไม่ได้** (เช่น FUTURO, ทูบีกริฟ)
- พยุงข้อเข่า เฉพาะข้อเข่าเสื่อมที่ยังไม่พร้อมผ่าตัด แพทย์ต้องระบุอาการ
- รถนั่งคนพิการพับได้ เฉพาะผู้พิการ แนบใบรับรองแพทย์ระบุความพิการ

## ค่ายาช่อง "เบิกไม่ได้" ของ รพ.ราชการ
- ให้ รพ. ระบุชื่อยาและโรคที่รักษา หรือแนบใบรับรองแพทย์ — ถ้าไม่มี ถือว่าไม่ประสงค์เบิก (สก.(สก)ว 5315/2544)
- ต้องตรวจทะเบียน **อย.** ว่าเป็น "ยา" — ถ้าเป็นเครื่องสำอาง (เช่น Eucerin pH5) อาหารเสริม หรือเครื่องมือแพทย์ เบิกไม่ได้ (เช่น Mecobalamin จดเป็นยา เบิกได้)
- ยานอกบัญชียาหลักรหัส NED / NS / NX (เช่น รพ.มหาราชนครเชียงใหม่ ศูนย์ศรีพัฒน์) ต้องค้น อย. ทุกรายการ แม้มีใบรับรองการใช้ยานอกบัญชี

## แนวปฏิบัติการใช้สิทธิและวางเงินมัดจำ ศูนย์ศรีพัฒน์ (มช.)
- มีใบส่งตัว ช่วยยกเว้นเงินมัดจำแรกเข้า (ผู้ป่วยทั่วไป) แต่ไม่ครอบคลุมรายการที่เบิกไม่ได้
- ยอดค่ารักษาเกินสิทธิครบ 30,000 บาท หรือครบทุก 3 วัน ต้องชำระส่วนเกินเอง
- รายการ 11 รายการที่ศูนย์ศรีพัฒน์เรียกเก็บเอง: ค่าห้อง/อาหารส่วนเกิน, ยานอกบัญชีที่กรมบัญชีกลางไม่รับรอง, เวชภัณฑ์ 1-3, อาหารทางการแพทย์กลับบ้าน, เวชสำอาง, ค่าบริการ รพ. IPD, ทันตกรรม, เสริมความงาม/ลดอ้วน/ผิวหนัง, ผ่าตัดหุ่นยนต์, ฝังเข็ม, ค่าบริการอื่น ๆ
