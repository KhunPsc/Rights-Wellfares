# สถานพยาบาลที่มีหลักเกณฑ์เฉพาะ

| สถานพยาบาล | สถานะ / หลักเกณฑ์ | แหล่ง |
|---|---|---|
| รพ.ศิริราช ปิยมหาราชการุณย์ | ต้องแนบ**ใบรับรองแพทย์ทุกครั้ง** ไม่แนบห้ามเบิก (กสก.(สก.)ว2869/2561) | ข้อ 36 |
| ศูนย์ศรีพัฒน์ คณะแพทยศาสตร์ มช. | แนบใบรับรองแพทย์ทุกครั้ง + มีสัญญาเงินเชื่อผู้ป่วยใน — ดู [[ศูนย์ศรีพัฒน์ มช]] | ข้อ 36 |
| รพ.ฟื้นฟูสมรรถภาพทางการแพทย์ลำปาง | สถานพยาบาลของ**ราชการ** — เบิกได้ | ข้อ 37 |
| ศูนย์ความเป็นเลิศทางการแพทย์ คณะแพทยศาสตร์ มช. | ไม่ใช่ราชการ และไม่ได้จดทะเบียนเป็นคลินิก — **เบิกไม่ได้** | ข้อ 38 |
| สสจ., สสอ. | สถานพยาบาลของราชการ — เบิกได้ (กสก.(สก)ว 2970/2561) | ข้อ 39 |
| สถานีอนามัย | สถานพยาบาลของราชการ — เบิกได้ (บผ.(สก)3453/2550) | ข้อ 39 |
| รพ.ราชวิถี (และ รพ.ราชการที่ต้องใช้หนังสือจากสำนักงานใหญ่) | หนังสือรับรองสิทธิออกโดย ผอ.กองสวัสดิการ | ข้อ 40.4 |
| รพ.ศิริราช — ค่าบริการ OPD ช่องเบิกไม่ได้ | เบิกได้ | ข้อ 22 |
| รพ.พญาไท 1 — ค่าบริการทางการแพทย์อื่น ๆ | เบิกไม่ได้ (เซอร์วิสชาร์จ) | ข้อ 22 |
| รพ.จุฬาลงกรณ์ — คลินิกพิเศษผู้ป่วยใน +20% | เบิกไม่ได้ | ข้อ 22 |
| รพ.มหาราชนครเชียงใหม่ / ศรีพัฒน์ — ยารหัส NED, NS, NX | ตรวจทะเบียน อย. ทุกรายการ | ข้อ 21 |

ข้อยกเว้นใบรับรองแพทย์ (ศิริราช/ศรีพัฒน์) กรณีส่งยาออกฤทธิ์ต่อระบบประสาททางไปรษณีย์ (ส่งได้ครั้งละไม่เกิน 30 วัน): เบิกพร้อมกันแนบต้นฉบับใบรับรองแพทย์ · เบิกทีละคราวภายหลัง แนบใบเสร็จ + ใบสั่งยาแต่ละคราว + สำเนาใบรับรองแพทย์วันที่เข้ารักษา

แหล่ง: [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] (ข้อตามตาราง)
