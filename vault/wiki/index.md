# สารบัญ

- [[overview]] — ภาพรวมสวัสดิการ กฟภ. และตารางเปรียบเทียบพนักงาน/ลูกจ้าง
- [[log]] — บันทึกการเปลี่ยนแปลง

## สิทธิ (rights/)
- [[ผู้มีสิทธิและบุคคลในครอบครัว]] — ใครมีสิทธิ บุตร คู่สมรส บิดามารดา เงื่อนไข 6 เดือน บรรลุนิติภาวะ
- [[กำหนดเวลายื่นเบิก]] — 90 วัน / 30 วัน / 180 วัน และวิธีนับแต่ละกรณี
- [[การใช้สิทธิซ้ำซ้อนกับหน่วยงานอื่น]] — ข้าราชการ ประกันสังคม พ.ร.บ.รถ ประกันสุขภาพ คู่สมรสต่างหน่วยงาน

## สวัสดิการ (welfare/)
- [[ค่ารักษาพยาบาล พนักงาน]] — รพ.รัฐ 100% / เอกชน IPD 50% / OPD 3,600 บาท/ปี / พยาบาลพิเศษ / เจ็บป่วยจากงาน
- [[ค่ารักษาพยาบาล ลูกจ้าง]] — รพ.เอกชน IPD ≤ 8,000 บาท / บุตร 1–3 คน
- [[ค่าห้องและค่าอาหาร]] — 1,500 / 1,100 / 1,000 บาท/วัน
- [[ค่ารักษาพยาบาลกรณีฉุกเฉิน]] — ป่วยหนักกะทันหัน (หลักฐาน 9 รายการ) / UCEP / โควิด-19
- [[รายการค่ารักษาที่เบิกได้และเบิกไม่ได้]] — ค่ายา แล็บ เอกซเรย์ ล้างไต อวัยวะเทียม ทันตกรรม ช่องเบิกไม่ได้
- [[เงินช่วยเหลือบุตร]] — พนักงาน 500 / ลูกจ้าง 200 บาท/เดือน
- [[เงินช่วยเหลือการคลอดบุตร]] — 1,200 บาท/ครั้ง
- [[ค่าเล่าเรียนบุตร]] — รัฐเต็มจำนวน / เอกชนครึ่งหนึ่ง (ปริญญาตรีขึ้นไป)
- [[ค่าตรวจสุขภาพประจำปี]] — พนักงานไม่จำกัด / ลูกจ้าง 580–1,050 บาท
- [[ค่าทำศพและค่าทดแทนทุพพลภาพ ลูกจ้าง]] — 3 เท่าค่าจ้าง ≥ 40,000 / 33.33% 15 ปี
- [[เบี้ยเลี้ยงและค่าเช่าที่พัก]] — อัตราตามระดับ และการระบุ TAX (⚠️ 2 ชุดไม่ตรงกัน)
- [[ค่าใช้จ่ายเดินทางไปปฏิบัติงาน]] — ใครเบิกได้ นับวัน ที่พัก ค่าพาหนะ รถส่วนตัว 5 บาท/กม. เงินยืม
- [[ค่าทำศพพนักงานและเงินช่วยเหลืออุปสมบท]] — 3 เท่า + 100,000 / อุปสมบท 2,000
- [[ค่าล่วงเวลา งานกะ และค่าอยู่เวร]] — OT 1 / 1.5 / 3 เท่า · ค่าอยู่เวร 150–205 บาท
- [[เงินเพิ่มพิเศษและค่าตอบแทนเฉพาะงาน]] — ฮอทไลน์ 150 บาท/วัน · ขับรถบรรทุก 75–100 บาท/วัน
- [[รถส่วนตัว เครื่องแบบ และยานพาหนะ]] — เงินชดเชยรถส่วนตัว · น้ำมัน 40–60 ลิตร · เครื่องแบบ 1,200 + รองเท้า 300
- [[พื้นที่พิเศษ ขนย้าย และฝึกอบรม]] — พื้นที่พิเศษ 2,000 บาท/เดือน · ค่าขนย้าย · วิทยากร/อาหารว่าง
- [[ละเมิดการใช้ไฟฟ้า เงินรางวัล และผ่อนชำระ]] — รางวัลผู้แจ้ง · ผ่อนชำระค่าเสียหาย

## หน่วยงาน / สถานพยาบาล (agencies/)
- [[สถานพยาบาลที่มีหลักเกณฑ์เฉพาะ]] — ศิริราช ฟื้นฟูลำปาง ศูนย์ความเป็นเลิศ มช. สสจ. สถานีอนามัย
- [[ศูนย์ศรีพัฒน์ มช]] — สัญญาเงินเชื่อผู้ป่วยใน ขั้นตอน ส่วนลด

## แบบฟอร์มและขั้นตอน (forms/)
- [[แบบฟอร์ม สก.2-ป.59]] — คำขอหนังสือรับรองการมีสิทธิ
- [[แบบฟอร์ม สก.5-ป.59]] — คำร้องและใบสำคัญจ่ายเงินค่ารักษาพยาบาล
- [[หนังสือรับรองสิทธิและการอนุมัติจ่าย]] — ใครออกหนังสือ การจ่ายเงิน อำนาจอนุมัติ
- [[ใบกำกับภาษีและภาษีมูลค่าเพิ่ม]] — สาระสำคัญ ภาษีซื้อต้องห้าม ใบแทน
- [[รักษาการแทนและปฏิบัติงานแทน]] — ใครรักษาการ มอบอำนาจอะไรได้/ไม่ได้
- [[ค่าใช้จ่ายดำเนินงานของหน่วยงาน]] — พวงหรีด เจ้าภาพงานศพ ค่ารับรอง น้ำดื่ม จ้างพาหนะ
