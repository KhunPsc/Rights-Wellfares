# การใช้สิทธิซ้ำซ้อนกับหน่วยงานอื่น

## หลักทั่วไป
1. ไม่มีสิทธิจากหน่วยงานอื่น → เบิก กฟภ.
2. มีสิทธิจากราชการ/หน่วยงานอื่น (รวม พ.ร.บ.รถ, ประกันสังคม) → **ใช้สิทธินั้นก่อน** ถ้าได้ต่ำกว่าสิทธิ กฟภ. เบิกส่วนที่ขาดได้
3. **ประกันสุขภาพส่วนตัว ไม่ถือเป็นหน่วยงานอื่น** → เบิก กฟภ. ได้เต็มสิทธิ

แหล่ง: [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 8, 26

## วิธีคำนวณส่วนที่ขาด
คำนวณสิทธิ กฟภ. จากใบเสร็จเต็มก่อน แล้วหักเงินที่ได้จากหน่วยงานอื่น (รายการเดียวกัน)

> ใบเสร็จ รพ.เอกชน 10,000 บาท เบิกหน่วยงานอื่นได้ 3,000 บาท → สิทธิ กฟภ. คำนวณได้ 5,000 → เบิก กฟภ. ได้อีก **2,000 บาท** · ถ้าสิทธิ กฟภ. ได้ ≤ 3,000 บาท ไม่มีส่วนที่ขาด

แหล่ง: [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 8.4

## คู่สมรสทำงานต่างหน่วยงาน — ใครใช้สิทธิของบุตร
ใช้เหมือนกันทั้งค่ารักษา ค่าเล่าเรียน และเงินช่วยเหลือบุตร

| คู่สมรส | ผู้ใช้สิทธิ |
|---|---|
| พนักงาน กฟภ. + ข้าราชการ | ฝ่ายพนักงาน กฟภ. (เงินช่วยเหลือบุตร: ดูหมายเหตุ) |
| พนักงาน กฟภ. ทั้งคู่ | ฝ่ายสามี |
| พนักงาน กฟภ. + รัฐวิสาหกิจอื่น | ฝ่ายสามีก่อน ถ้าต่ำกว่า ภรรยาเบิกเพิ่มส่วนที่ต่ำกว่า |
| หย่า / แยกกันอยู่ | ฝ่ายที่ปกครองหรืออุปการะบุตร เฉพาะบุตรที่อยู่กับตน (ถ้าฝ่ายนั้นไม่มีสิทธิจากต้นสังกัด พนักงาน กฟภ. ใช้สิทธิได้) |
| พนักงาน + ลูกจ้าง กฟภ. | ฝ่ายพนักงาน |

> [!note] เงินช่วยเหลือบุตรพนักงานใช้กฎต่างออกไปเล็กน้อย
> คู่สมรสเป็นพนักงาน กฟภ. หรือสังกัดหน่วยงานอื่น ให้**ฝ่ายสามี**ใช้สิทธิฝ่ายเดียว ถ้าคู่สมรสใช้สิทธิจากราชการ/หน่วยงานอื่นแล้วต่ำกว่า เบิกส่วนที่ต่ำกว่าได้ ([[ระเบียบ เงินช่วยเหลือบุตร 2561]] ข้อ 7)

แหล่ง: [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 13 · [[ระเบียบกองทุน ค่าเล่าเรียนบุตร 2560]] ข้อ 5 · [[คำสั่ง พ.(ท) 1-2565 สวัสดิการลูกจ้าง]] ข้อ 5.1, 10.4, 11.3

## พนักงานกับคู่สมรสที่เป็นลูกจ้าง กฟภ.
ลูกจ้างเบิกค่าห้องได้ ≤ 1,000 บาท/วัน → พนักงานเบิกส่วนเกินในฐานะคู่สมรส (เพดาน 1,100) ได้อีก ≤ 100 บาท/วัน (กสก.(สก.)ว3470/2558) ([[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 8.1)

## บิดามารดาที่มีบุตรเป็นข้าราชการด้วย
(กสก.(สก.)ว 2802/2559)
- บิดา/มารดาเป็นข้าราชการหรือข้าราชการบำนาญ → ใช้สิทธิราชการก่อน
- บิดามารดาไม่มีอาชีพ มีบุตรอยู่ กฟภ. และรับราชการ:
  - เคยใช้สิทธิทั้งสองแห่ง หรือเคยใช้แต่ราชการ → ใช้ราชการก่อน
  - ไม่เคยใช้ราชการ ใช้ กฟภ. มาตลอด → ใช้ กฟภ. ต่อได้
- พนักงาน กฟภ. ทั้งคู่ มีบุตรรับราชการ ต่อมาฝ่ายหนึ่งพ้นสภาพ → ฝ่ายที่ยังเป็นพนักงานใช้สิทธิ กฟภ. ได้ (แต่ถ้าภายหลังบุตรนำไปเบิกราชการ ต่อไปต้องใช้ราชการก่อน)
- ไม่สะดวกใช้สิทธิราชการ (เช่น บุตรย้ายไปพื้นที่ทุรกันดาร) → ชี้แจงเสนอที่ประชุม กกท. เป็นราย ๆ

ตัวอย่างครอบครัวหลายหน่วยงาน: [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 10

แหล่ง: [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 9

## อ้างว่าหน่วยงานราชการไม่ให้เบิก
ต้องมีหนังสือรับรองจากหน่วยงานนั้นว่าเบิกไม่ได้เพราะอะไร — ถ้าเป็น รพ.เอกชน คนไข้ใน และมีใบรับรองแพทย์ว่าฉุกเฉินอันตรายถึงชีวิต ต้องสอบถามหน่วยงานนั้นก่อนว่าทำไมเบิกไม่ได้ (กค 0422.2/ว 95 ลว. 25 เม.ย. 2557) ([[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 11)

## นำใบเสร็จไปเบิกที่อื่นก่อน
สำเนาทุกฉบับต้องให้เจ้าหน้าที่หน่วยงานนั้นรับรองสำเนาถูกต้อง พร้อมลายเซ็น ชื่อ-สกุลตัวบรรจง และตำแหน่ง ([[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 12) — นับ 90 วันจากวันที่หน่วยงานนั้นอนุมัติจ่าย ([[กำหนดเวลายื่นเบิก]])

## ประกันสุขภาพส่วนตัว
เบิก กฟภ. ได้เต็มสิทธิ ใช้สำเนาเอกสารได้ โดยการรับรองสำเนามีไว้บอกว่าต้นฉบับอยู่ที่ใด
- จ่าย รพ. เองทั้งหมดแล้วไปเบิกประกัน → บริษัทประกันรับรองสำเนาใบเสร็จ ใบหน้างบสรุป ใบรับรองแพทย์ ระบุว่าต้นฉบับอยู่ที่บริษัท
- รพ. เก็บจากประกันบางส่วน จากผู้ป่วยบางส่วน (ใบเสร็จ 2 ฉบับ) → แนบใบเสร็จจริงส่วนที่จ่ายเอง + สำเนาใบเสร็จส่วนประกัน (รับรองโดยบริษัทหรือ รพ.) + ใบหน้างบสรุปทั้งหมด

แหล่ง: [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 26 (สก.(สก.)ว 1886/2545)

## พ.ร.บ.คุ้มครองผู้ประสบภัยจากรถ
- ผู้ขับขี่ ผู้โดยสาร คนเดินเท้า บาดเจ็บจากรถ → ยื่นขอค่าเสียหายเบื้องต้นภายใน **180 วัน** ก่อน แล้วเบิกส่วนที่ขาดจาก กฟภ.
- ค่าเสียหายเบื้องต้น: จ่ายจริงไม่เกิน **30,000 บาท/คน** ภายใน 7 วัน ไม่ต้องรอพิสูจน์ความผิด
- รถไม่มี พ.ร.บ. และไม่มีคู่กรณี → ถูกหัก 30,000 บาทจากสิทธิ กฟภ.
- ตัวอย่าง: ค่ารักษา รพ.เอกชน 80,000 สิทธิ กฟภ. 50,000 หักค่าเสียหายเบื้องต้น 30,000 → เบิก กฟภ. **20,000 บาท**

แหล่ง: [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 25

## ประกันสังคม
### ผู้ประกันตนมาตรา 33 (บุคคลในครอบครัว)
ต้องรักษาที่ รพ. ตามบัตรรับรองสิทธิหรือเครือข่าย — ไปที่อื่นเอง **เบิก กฟภ. ไม่ได้** (บผ.(สก.)ว3031/2551) ยกเว้น:
- อุบัติเหตุ/ฉุกเฉินเร่งด่วน เข้า รพ. ใกล้ที่สุด แล้วแจ้ง รพ. ตามบัตรโดยด่วน (ปกส. รับผิดชอบช่วงก่อนแจ้งภายใน 72 ชม.)
- ทันตกรรม: ถอน/อุด/ขูดหินปูน/ผ่าฟันคุด ≤ 900 บาท/ปี · ฟันเทียมบางส่วน 1–5 ซี่ ≤ 1,300 / >5 ซี่ ≤ 1,500 · ทั้งปาก บนหรือล่าง ≤ 2,400 / บนและล่าง ≤ 4,400 (ภายใน 5 ปี)
- คลอดบุตร: เหมาจ่าย 15,000 บาท/ครั้ง ไม่จำกัดครั้ง
- ฝากครรภ์: รวม 1,500 บาท (≤12 สัปดาห์ 500 / 12–20 สัปดาห์ 300 / 20–28 สัปดาห์ 300 / 28–32 สัปดาห์ 200 / 32–40 สัปดาห์ 200)
- สงเคราะห์บุตร: 800 บาท/เดือน/คน อายุไม่เกิน 6 ปี คราวละไม่เกิน 2 คน

> [!warning] ข้อมูลขัดแย้ง — อัตราประกันสังคม
> ฉบับเว็บ (ข้อ 27) ระบุคลอดบุตร 15,000 และสงเคราะห์บุตร 800 บาท แต่ PDF คู่มือระบุ 13,000 และ 600 บาท (ฉบับเก่ากว่า) ([[คู่มือตรวจสอบสิทธิ์สวัสดิการ]]) — ตรวจกับประกาศสำนักงานประกันสังคมปัจจุบัน

- ลาออกแต่ยังส่งเงินสมทบ → สิทธิเหมือนเดิม (หยุดส่งเกิน 3 เดือนติดกัน ขาดสิทธิ) · ลาออกและไม่ส่งต่อ → ยังได้สิทธิรักษาจาก ปกส. อีก 6 เดือน
- 13 กลุ่มโรค/บริการที่ ปกส. ไม่คุ้มครอง: สารเสพติด, บำบัดทดแทนไต (ยกเว้นไตวายระยะสุดท้าย), ความสวยงาม, การรักษาระหว่างทดลอง, มีบุตรยาก, ตรวจเนื้อเยื่อเพื่อเปลี่ยนอวัยวะ, ตรวจเกินจำเป็น, ผ่าตัดเปลี่ยนอวัยวะ (มีข้อยกเว้น), เปลี่ยนเพศ, ผสมเทียม, พักฟื้น, ทันตกรรม (ยกเว้นที่กล่าวไว้), แว่นตา

### ผู้ประกันตนมาตรา 39 และ 40
ไม่อยู่ใต้ข้อจำกัดของมาตรา 33 → เบิก กฟภ. ได้ตามสิทธิปกติ

## ค่าสินไหมทดแทนจากบุคคลอื่น (ลูกจ้าง)
ได้ค่าสินไหมทดแทนค่ารักษาแล้ว ไม่มีสิทธิ เว้นแต่ได้ต่ำกว่า ถ้าเบิกไปก่อนแล้วได้ค่าสินไหมภายหลัง ต้องส่งคืน (เฉพาะค่าสินไหมส่วนค่ารักษา ไม่รวมค่าทำขวัญ) ([[คำสั่ง พ.(ท) 1-2565 สวัสดิการลูกจ้าง]] ข้อ 5.6) — แบบ [[แบบฟอร์ม สก.5-ป.59]] ก็มีช่องรับรองว่าจะคืนเงินเช่นกัน
