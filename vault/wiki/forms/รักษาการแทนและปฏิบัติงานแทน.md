# รักษาการแทนและปฏิบัติงานแทน

ตามข้อบังคับ กฟภ. ว่าด้วยระเบียบพนักงาน พ.ศ. 2517 ข้อ 9–10 — สรุปจาก [[คู่มือตรวจสอบใบสำคัญจ่ายเงิน กฟน.1 (26 ม.ค.65)]] หน้า 73–75

## รักษาการแทน (ปฏิบัติหน้าที่แทนชั่วคราว ทุกอำนาจ)
ใช้เมื่อตำแหน่ง**ว่าง**และยังไม่ได้แต่งตั้งใคร หรือผู้ดำรงตำแหน่ง**ปฏิบัติงานไม่ได้** (ไปราชการ ลา)

| มีตำแหน่งรอง/ผู้ช่วยหรือไม่ | ผู้รักษาการแทน |
|---|---|
| มี | **รอง** แล้วจึง **ผู้ช่วย** เป็นโดยอัตโนมัติ (มีหลายคน ต้องแต่งตั้งเป็นหนังสือเรียงลำดับ) |
| ไม่มี หรือมีแต่ปฏิบัติงานไม่ได้ | **ผู้บังคับบัญชาชั้นเหนือ**แต่งตั้งพนักงานที่เห็นสมควร |

- ผู้รักษาการแทนมีอำนาจหน้าที่**เช่นเดียวกับผู้ที่ตนแทน**
- ตัวอย่าง: ผจก.กฟจ.เชียงใหม่ไม่อยู่ → รจก./ชจก. รักษาการ (แต่งตั้งเรียงลำดับ) · ถ้าไม่มี → ผชก.(น1) แต่งตั้ง · หผ.บห. ไม่อยู่ → ชผ.บห. รักษาการโดยไม่ต้องมีคำสั่ง · ถ้าไม่มี → ผจก. แต่งตั้ง
- กฟฟ. มี รจก. 2 คน การเรียงลำดับเป็นอำนาจ ผชก.(น1)
- **แต่งตั้งไม่ถูกต้อง นิติกรรม/คำสั่งที่ทำไปไม่มีผลสมบูรณ์** (นก.(บห.)122/2549)

## ปฏิบัติงานแทน (มอบอำนาจเฉพาะเรื่อง)
ถ้าระเบียบเรื่องนั้นไม่ได้กำหนดเรื่องการมอบอำนาจไว้เป็นอย่างอื่น ผู้ดำรงตำแหน่ง (หรือผู้รักษาการแทน) **มอบอำนาจเป็นหนังสือ**ให้รอง/ผู้ช่วย หรือถ้าไม่มี ให้พนักงานที่เห็นสมควร — ผู้รับมอบมีอำนาจ**เท่าที่ได้รับมอบ**

| มอบให้ปฏิบัติงานแทน**ได้** | มอบ**ไม่ได้** (อำนาจเฉพาะตำแหน่ง) |
|---|---|
| อนุญาตการลาของพนักงาน | อนุมัติซื้อ / จ้าง / เช่า |
| กำกับดูแลงานในความรับผิดชอบ | อนุมัติสั่งจ่ายเงินตามระเบียบการเงิน |
| อนุมัติการเดินทางที่ระเบียบเขียนว่า "ผชก. หรือผู้ที่ได้รับมอบหมาย" (ลงนาม รบ.19-ป.57 และประทับตรา "ปฏิบัติงานแทน") | |
