# แบบ สก.5-ป.59

**แบบคำร้องและใบสำคัญจ่ายเงินค่ารักษาพยาบาล** — ใช้ยื่นเบิกค่ารักษาที่จ่ายเงินไปแล้ว ([[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 41.1) · ลูกจ้างใช้แบบเดียวกัน ([[คำสั่ง พ.(ท) 1-2565 สวัสดิการลูกจ้าง]] ข้อ 13)

## ส่วนของแบบ
1. **ผู้ขอเบิก**: ชื่อ เลขประจำตัว ตำแหน่ง สังกัด เบอร์ภายใน วันบรรจุ · ผู้ป่วยและความสัมพันธ์ อาชีพ สถานที่ทำงาน (ระบุถ้าเป็นข้าราชการประจำ/บำนาญ) · สถานพยาบาล (ราชการ/เอกชน) จังหวัด โรค ช่วงวันที่ · จำนวนหลักฐานที่แนบ · ยอดเงิน แยกไม่รวม VAT และ VAT
2. **ขอเบิกตามสิทธิ** (เลือก): เต็มจำนวนที่จ่ายจริง / ครึ่งหนึ่ง / เฉพาะส่วนที่ขาดเพราะสิทธิจากต้นสังกัดต่ำกว่า / เฉพาะส่วนที่ขาดเพราะค่าสินไหมทดแทนจากบุคคลภายนอกต่ำกว่า (ได้ค่าสินไหมภายหลัง ต้องคืน กฟภ. ทันที)
3. **คำรับรอง**: ผู้ป่วยมีสิทธิตามระเบียบ / ไม่มีสิทธิจากราชการหรือหน่วยงานอื่น หรือได้บางส่วน / ข้อความเป็นจริง
4. **ความเห็นหน่วยงานที่สังกัด → ผู้ตรวจสอบ → ผู้ตรวจจ่าย → อนุมัติจ่าย** (อฝ./อก./ผจก.) และช่องผู้รับเงิน/ผู้จ่ายเงิน

แหล่ง: [[แบบคำร้องและใบสำคัญจ่ายเงินค่ารักษาพยาบาล]]

## ยื่นภายใน
90 วันนับจากวันที่ในใบเสร็จ — ดู [[กำหนดเวลายื่นเบิก]]

## หลักฐานที่มักต้องแนบ
- ใบเสร็จรับเงิน (ต้นฉบับ ยกเว้นกรณีประกันสุขภาพหรือเบิกหน่วยงานอื่นก่อน ใช้สำเนารับรองได้)
- IPD: หนังสือรับรองการเจ็บป่วย/ใบรับรองแพทย์
- OPD เอกชน/คลินิก: ใบรับรองแพทย์ รายละเอียดเวชภัณฑ์
- แพทย์สั่งให้ทำ/ซื้อข้างนอก: ใบสั่งแพทย์ ใบรับรองรายการที่ไม่มีจำหน่าย
- ป่วยหนักกะทันหัน: 9 รายการ ดู [[ค่ารักษาพยาบาลกรณีฉุกเฉิน]]
- ศิริราช / ศรีพัฒน์: ใบรับรองแพทย์ทุกครั้ง
