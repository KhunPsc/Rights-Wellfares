# หนังสือรับรองสิทธิและการอนุมัติจ่าย

## ใครออกหนังสือรับรองสิทธิ (รพ.ราชการ)
ยื่น [[แบบฟอร์ม สก.2-ป.59]] พร้อมระบุสาเหตุที่เข้ารักษา
| กรณี | ผู้ออก |
|---|---|
| ส่วนภูมิภาค | ผู้บังคับบัญชาสูงสุดของหน่วยงานที่ผู้ปฏิบัติงานสังกัด |
| รพ.ราชวิถี / รพ.ราชการที่ต้องใช้หนังสือจากสำนักงานใหญ่ | ผอ.กองสวัสดิการ (กสก.) |
| ไปปฏิบัติงานต่างพื้นที่ หรือออกให้บุคคลในครอบครัว | ผู้บังคับบัญชาสูงสุดของหน่วยงานที่ไปปฏิบัติงาน หรือหน่วยงานต้นสังกัด |
| รพ.เอกชน | ออกได้**เฉพาะเจ็บป่วย/อุบัติเหตุจากการทำงานให้ กฟภ.** (ชผก. ออก โดยอนุมัติ รผก.(ท)) |
| ศูนย์ศรีพัฒน์ มช. | กอก.กฟน.1 — ดู [[ศูนย์ศรีพัฒน์ มช]] |

แหล่ง: [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 40, 35.3.2

## การจ่ายเงินให้สถานพยาบาล (เมื่อได้ใบแจ้งหนี้)
- **ส่วนภูมิภาค**: หน่วยงานต้นสังกัดที่ออกหนังสือรับรอง ตรวจสิทธิและหลักฐาน แล้วเสนอผู้มีอำนาจอนุมัติจ่าย
- **สำนักงานใหญ่**: ส่งกองตรวจจ่ายขออนุมัติ กองการเงินจ่าย
- **UCEP / โควิด-19** (สปสช. แจ้งยอด): กองสวัสดิการตรวจ → กองตรวจจ่ายขออนุมัติ → กองการเงินจ่าย
- จ่ายเป็น**เช็คขีดคร่อม** ขีดฆ่า "หรือตามคำสั่ง" / "หรือผู้ถือ" สั่งจ่ายในนามสถานพยาบาล (หน่วยงานของมหาวิทยาลัย: ในนามสถานพยาบาลหรือมหาวิทยาลัย และส่งเช็คให้สถานพยาบาลโดยตรง)
- เรียกเก็บเกินสิทธิ: เรียกคืนจากพนักงาน คืนภายใน **30 วัน**นับแต่ทราบ

แหล่ง: [[ระเบียบกองทุน รักษาพยาบาล ฉ.2 2564]] ข้อ 25 · [[คู่มือตรวจสอบสิทธิ์สวัสดิการ]] ข้อ 42

## อำนาจอนุมัติจ่ายค่ารักษาพยาบาล
ตามระเบียบ กฟภ. ว่าด้วยการเงิน (ฉบับปรับปรุง) พ.ศ. 2558 ข้อ 37.5
| ผู้อนุมัติ | วงเงิน |
|---|---|
| ผู้ช่วยผู้ว่าการ (ชผก.) | ตามที่จ่ายจริง |
| ผอ.ฝ่าย (เขต), ผจก.กฟภ. ชั้น 1 | ≤ 300,000 บาท |
| ผอ.กอง (เขต), ผจก.กฟภ. ชั้น 2–3 | ≤ 100,000 บาท |
| ผจก.กฟภ. สาขา | ≤ 50,000 บาท |

เกินอำนาจ: ขออนุมัติผู้บังคับบัญชาที่มีอำนาจตามลำดับชั้น
