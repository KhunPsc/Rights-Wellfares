# raw/

เอกสารต้นฉบับ — **ไม่แก้ไขไฟล์ในนี้** วางไฟล์แล้วสั่ง ingest ตามขั้นตอนใน CLAUDE.md

- `pdf/` — PDF ต้นฉบับ **เก็บในเครื่องเท่านั้น ไม่ขึ้น git** (`.gitignore`) · ตั้งชื่อสั้น (ภาษาไทย 1 ตัว = 3 ไบต์ ชื่อเกิน 255 ไบต์เปิดไม่ได้)
- `text/` — ข้อความที่สกัด/ถอดจาก PDF หรือภาพสแกน ใช้อ่านแทน PDF (ไฟล์ที่ถอดจากภาพมีหมายเหตุบรรทัดแรก)
- `assets/` — รูปต้นฉบับ · รูปที่หนังสือใช้ (`![...](../../raw/assets/...)`) ถูกคัดลอกไป `docs/assets/raw/` และ**เผยแพร่สาธารณะ**บน GitHub Pages
- `google-site/` — เนื้อหาจาก Google Sites เดิม (ก่อนย้ายมาเป็นหน้าเว็บหลายหน้า)
