ที่มา: ระเบียบ กฟภ. ว่าด้วยการจ่ายสินบนและเงินรางวัล ให้แก่ผู้นำจับหรือผู้จับผู้กระทำผิดลักอุปกรณ์ระบบไฟฟ้า พ.ศ. 2546

## 1. คำนิยาม
| คำ | ความหมาย |
|---|---|
| 1.1 เงินสินบน | เงินที่จ่ายให้แก่บุคคลผู้นำจับ |
| 1.2 เงินรางวัล | เงินที่จ่ายให้แก่บุคคลผู้ซึ่งจับกุมผู้กระทำผิด |
| 1.3 ผู้นำจับ | บุคคลที่นำความมาแจ้งต่อพนักงานเจ้าหน้าที่ให้ทำการจับกุมผู้กระทำผิดลักอุปกรณ์ระบบไฟฟ้า |
| 1.4 ผู้จับ | พนักงานฝ่ายปกครอง หรือตำรวจ หรือบุคคลที่มีอำนาจจับตามกฎหมาย เป็นผู้จับกุมผู้กระทำผิด |
| 1.5 พนักงานเจ้าหน้าที่ | พนักงานฝ่ายปกครอง หรือตำรวจหรือพนักงานของการไฟฟ้าส่วนภูมิภาค |
| 1.6 อุปกรณ์ระบบไฟฟ้า | อุปกรณ์ของระบบไฟฟ้าที่ติดตั้งไว้แล้ว อันประกอบด้วย เสา สายไฟฟ้า หม้อแปลงไฟฟ้า มิเตอร์ และส่วนประกอบอื่น ๆ |

## 2. เงื่อนไขการจ่าย
การจ่ายเงินสินบนแก่ผู้นำจับ และเงินรางวัลแก่ผู้จับผู้กระทำผิดลักอุปกรณ์ระบบไฟฟ้าแต่ละครั้ง จะจ่ายให้เมื่อตรวจสอบแล้ว ปรากฏหลักฐานแน่ชัดว่าผู้ถูกจับกระทำผิดจริง และได้มีการยื่นฟ้องบุคคลดังกล่าวต่อศาลแล้ว

## 3. เงินสินบนและเงินรางวัล
- 3.1 ผู้นำจับ จ่ายเงินสินบนให้ **2,000.- บาท**
- 3.2 ผู้จับ จ่ายเงินรางวัลให้ **2,000.- บาท**

## 4. ผู้นำจับหลายคน
การจับผู้กระทำผิดแต่ละครั้ง ถ้ามีผู้นำจับหลายคนจะพิจารณาจ่ายเงินสินบนให้แก่ผู้นำจับคนแรกเท่านั้น ถ้ามีผู้นำจับหลายคนพร้อมกันจะพิจารณาแบ่งจ่ายเงินสินบนตามส่วน

## 5. ผู้จับหลายคน
ในการจับผู้กระทำผิดแต่ละครั้ง ถ้ามีผู้จับหลายคนจะพิจารณาแบ่งจ่ายเงินรางวัลตามส่วน

## 6. อำนาจอนุมัติ
อำนาจอนุมัติสั่งจ่ายเงินสินบนหรือเงินรางวัล เป็นอำนาจของผู้ช่วยผู้ว่าการ ผู้จัดการการไฟฟ้าชั้น 1-3 หรือผู้รักษาการแทนตำแหน่งดังกล่าว
